# Self-Projects Repository

Welcome to my Self_Projects repository! This collection showcases various AI and Machine Learning projects I've undertaken, focusing on areas such as LLM fine-tuning, Retrieval-Augmented Generation (RAG), Sports News Generation, News Classification and many more to come later...

## Projects:

### 1. **Fine-Tuning an LLM using PEFT QLoRA**
- **Description:** Fine-tuned a multilingual conversational dataset using Parameter Efficient Fine-Tuning (PEFT) with QLoRA.
- **Highlights:**
  - Optimized memory usage to train models on consumer GPUs.
  - Enhanced model performance on specific language tasks.

### 2. **Generating Sports News with SmolLM-135M and SmolLM2-1.5B model**
- **Description:** Fine-tuned the lightweight SmolLM-135M and SmolLM2-1.5B model for sports news generation.
- **Highlights:**
  - Implemented efficient text generation pipelines.
  - Achieved optimized inference for real-time applications.

### 3. **News Classification using DistilBERT**
- **Description:** Fine-tuned DistilBERT for multi-class news classification tasks.
- **Highlights:**
  - Developed efficient text preprocessing techniques.
  - Conducted comprehensive model evaluation to ensure accuracy.

### 4. **Conversational Retrieval-Augmented Generation (RAG)**
- **Description:** Built an interactive chatbot using LangChain, ChromaDB, and OpenAI models, integrating PDF parsing for document-based Q&A.
- **Highlights:**
  - Enhanced user interaction through conversational AI.
  - Provided accurate and context-aware responses.
